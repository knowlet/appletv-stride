# Apple TV Stride

A local-first indoor walking and slow-jogging app: motion from an iPhone controls a native Apple TV scene. Apple Watch support and licensed street-level imagery are planned as separate adapters.

## Development

The default branch is `develop`. Implementation changes are reviewed in feature-branch pull requests. Device support, setup instructions, and verification status are documented alongside each implementation; a successful simulator build is not a substitute for a real-device exercise test.
